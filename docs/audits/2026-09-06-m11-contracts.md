## 配置输入 Interface

```python
from app.crawlers.schema import InvalidRecipe, validate_recipe

recipe = validate_recipe({
    "format_version": 1,
    "output_contract": "article.v1",
    "target_kind": "news",
    "source_id": 42,
    "locale": "fr",
    "transport": "http",
    "identity_policy": "legacy-compatible-url-v1",
    "list_pages": [{
        "url": "https://news.example.invalid/actualites/",
        "item_selector": "article.news-card",
        "fields": {
            "title": {"selector": "h2 a", "read": "text"},
            "url": {"selector": "h2 a", "read": "attr", "attr": "href"}
        }
    }]
})
snapshot = recipe.to_dict()   # 独立副本，修改不影响recipe
fingerprint = recipe.fingerprint  # 规范JSON的SHA256，与对象键顺序无关
```

- 接受JSON文本或纯JSON字典；拒绝重复key、NaN/Infinity、Python对象/非字符串key、畸形或超限输入。
- `ValidatedRecipe`是返回的数据类型；应用调用方始终经`validate_recipe`导入，不直接构造它来绕过验证。
- `InvalidRecipe`提供`code/path`，只返回固定原因及已知字段路径，不把不可信值、额外字段名或解析异常全文带入错误消息。
- 所有层级字段采用允许列表。拒绝active、模型/作者元信息、headers/凭据、预算/域名权限/质量阈值、任意Python/JS/regex/transform/evaluate。
- 固定news/article.v1/http/legacy-compatible-url-v1；locale是受限语言标签（如fr、en、zh-CN）或unknown，不猜旧文章语言。
- `extractor`省略时为html；显式html同样可用。省略可选字段和显式写出字段的JSON可能有不同指纹，这是配置身份而非语义等价判定。

### 提取配置形式（只校验，不执行）

- HTML：`list_pages`中的item_selector与title/url必需字段；可选next_link分页。`detail_templates`按明确host/path_prefix匹配，至少有一个字段，支持remove_selectors。
- CSS字段：`text`、`paragraphs`或`attr`；attr只允许href/src/datetime/content/title/id。允许简单后代/子选择器、标签/class/id/属性选择器；拒绝列表、转义、伪类、兄弟遍历。属性中的`og:title`合法，不误作伪类。
- RSS：设置`extractor="rss"`，用`feed`替代list_pages。`feed.url`为HTTP(S)，`feed.fields`映射固定feedparser字段：title→title、url→link、external_id→id或link、content→content或summary、published_at→published或updated、author→author；title/url必需。可复用详情模板。不接受recipe自报content_level=full。
- JSON-LD：只用于详情模板，必须声明`jsonld_types`（Article/NewsArticle/Event）。字段用`{"read":"jsonld","path":["headline"]}`；允许固定路径如articleBody、description、datePublished、author.name、image.url，不支持JSONPath表达式或脚本执行。可与CSS字段混用。
- date_policy可声明IANA source_timezone；没有时区不等于允许把未知时间填成现在。

### 静态上限

| 项目 | 上限 |
|---|---:|
| JSON UTF-8大小 | 64KiB |
| 嵌套深度 / 值节点数 | 12 / 2048 |
| 列表页 / 详情模板 | 4 / 8 |
| 所有字段规则合计 | 64 |
| 选择器/字段读取数合计（JSON-LD字段也计入） | 128 |
| 单CSS长度 / 简单选择器段数 | 256字符 / 8段 |
| 每模板remove_selectors | 16 |
| 单列表分页max_pages | 10 |

字典在总序列化之前累计容量，最终规范JSON再次检查大小。合成大字典的峰值分配回归先测得2,997,058 bytes超出1MiB断言，加入累计检查后通过。此证据只针对该合成输入，不是实际DOM执行时间/资源验收。

**静态合法不代表域名获准、可访问私网、质量合格或已批准发布。** URL这里只做HTTP(S)/无userinfo/基本格式检查；DNS、私网、重定向、查询参数脱敏与实际请求预算属于Safe Fetch/执行策略。

## 标准结果 Interface

全部公开数据契约采用冻结dataclass；输入列表复制成tuple，外部修改不能更改已经返回的结果。

- `NormalizedArticle`：保留source_id/external_id/title/url、source_language、content_level、content、published_at及其来源、可选author/image_url和字段provenance。
  - title/external_id最多500字符，URL1000，author200；正文最多65,535 UTF-8 bytes，不静默截断。
  - metadata_only只允许content=None；full/excerpt需有非空、非纯HTML空壳正文及内容来源。
  - 默认语言unknown、日期None/unknown；非空日期必须带时区，统一UTC，拒绝无时区日期；不使用抓取时间补发布时间。
- `FieldProvenance`：字段名、css/feed/jsonld/legacy方法、快照引用与有限locator。提取方法需要来源引用；legacy允许显式未知证据，以便后续Adapter诚实标注，不能据此声称已验证旧结果。
- `FetchObservation`：请求/最终URL、UTC fetched_at、HTTP状态、快照引用、response_bytes、content_type和结构化错误；不携带HTML/headers。
  - status派生为ok/not_modified/retryable_error/blocked/failed。成功响应需证据，304可无新快照但不得带正文计数；401/403不能标为可重试timeout。
- `CrawlError`：固定stage/code和有限evidence_ids；retryable由错误码派生，不由输入任意指定。无任意错误正文。
- `QualityReport`：discovered/extracted/valid/duplicate/new/updated/rejected、no_change_reason和证据引用；没有模型自评分或可降低的阈值。
  - extracted表示已完成抽取并评估的候选，`valid + rejected == extracted <= discovered`。
  - `duplicate + new + updated <= valid`，允许尚未应用业务结果的中间报告；成功/部分成功等终态必须完整核对valid条目的处理去向。
- `CrawlOutcome`：run_id/status/quality、唯一article_ids、可选schema_version_id/quality_report_id、errors、repair_dispatched；article_ids数等于new+updated。

| 终态 | 内部一致性要求 |
|---|---|
| success | 有新增/更新ID，抽取完整、无拒绝或错误，valid全部有处理计数 |
| no_change | 无新增/更新或错误；not_modified/confirmed_empty/all_duplicates原因有证据；不能派发repair |
| partial | 有合格项和拒绝/错误，保留已完成的ID；允许全是重复的合格部分 |
| degraded | 有合格项且明确low_quality问题 |
| inconclusive | 无新增/更新；无证据的空结果保持此状态，不自动称作成功 |
| blocked | 无新增/更新且有访问受限错误 |
| failed | 无新增/更新且有结构化错误；可重试性由错误码决定 |

只有结构/抽取/内容失败原因允许repair_dispatched标志；仅网络超时/429/无新增不能触发该标志。这只是结果自洽检查，**没有实现学习派发、lease或outbox**。
